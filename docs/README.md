# Документация StockHelper

StockHelper — программа для учёта расходных материалов на предприятии: бумаги, картриджей, краски, перчаток, моющих средств и всего, что постоянно тратится. Программа показывает, сколько чего осталось, сколько тратится, когда что закончится и что пора купить.

## С чего начать

1. **[Общее руководство](general.md)** — прочитайте его первым, кем бы вы ни были. Здесь описано, как установить программу, войти, как устроен экран, что означают основные понятия (остаток, расход, прогноз, инвентаризация) и как работать с таблицами.
2. Затем откройте руководство для своей роли:
   - **[Руководство кладовщика](storekeeper.md)** — приём товара, выдача сотрудникам, возвраты, открытые упаковки, инвентаризация.
   - **[Руководство руководителя](manager.md)** — справочник позиций, отчёты, графики, список на закупку, контроль недостач.
   - **[Руководство администратора](administrator.md)** — первый запуск, пользователи и роли, места хранения, настройки, резервные копии, обновления.
